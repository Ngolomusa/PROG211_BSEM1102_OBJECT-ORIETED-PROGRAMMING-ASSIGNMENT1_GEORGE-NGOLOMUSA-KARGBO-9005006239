# Name of System : Student Learning Portal 
##  simple Python program for the  Object-Oriented Programming assignment (Student Learning Portal). 
It manages students, courses, and exam results and stores this data to be printed out


## Features of the system (Student Learning Portal )
- Register students and store them in a registry (dictionary)
- Track the total number of students created
- Display course details and student details
- Automatically calculate a grade from a score based on the scores recorded


## OOP Concepts Used
1.Classes and objects ( Student, Course, Result)
2.Class variables (Student.total_students, Student.University)
3.Instance variables (student_id, level, faculty, score) 
4.Class method (Student.get_total_student)
5.Static method (Result.calculate_grade())
